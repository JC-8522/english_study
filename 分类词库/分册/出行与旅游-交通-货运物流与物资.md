# 出行与旅游 / 交通 / 货运物流与物资

1. **cargo**，读音：/ˈkɑr.ˌɡoʊ/，重音：主重音第1音节，中文：货物；口语：① [Let's try and offload this cargo before lunch.](https://tatoeba.org/en/sentences/show/7004650) ② [There wasn't too much cargo to unload.](https://tatoeba.org/en/sentences/show/10765772)

2. **freight**，读音：/freɪt/，重音：单音节，中文：船货；运费；口语：① [How much freight did you carry last trip?](https://tatoeba.org/en/sentences/show/2253286) ② [How much is the freight on this box?](https://tatoeba.org/en/sentences/show/2253288)

3. **portage**，读音：/ˈpɔr.tədʒ/，重音：主重音第1音节，中文：陆上运输；搬运；口语：① [We have a few miles of portage.](https://tatoeba.org/en/sentences/show/6616584) ② Can we talk about the portage for a minute?

4. **shipments**，读音：/ˈʃɪp.mənts/，重音：主重音第1音节，中文：发货；运载的货物（shipment的复数）；口语：① [Food shipments were blocked.](https://tatoeba.org/en/sentences/show/805398) ② [Pietro unloaded truck shipments.](https://tatoeba.org/en/sentences/show/11717613)

5. **trucking**，读音：/ˈtrʌ.kɪŋ/，重音：主重音第1音节，中文：货车运输业；货车运输；口语：① [Yanni's trucking route is from Algiers to Bejaia.](https://tatoeba.org/en/sentences/show/9052702) ② Can we talk about the trucking for a minute?
