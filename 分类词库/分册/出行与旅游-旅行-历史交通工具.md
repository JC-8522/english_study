# 出行与旅游 / 旅行 / 历史交通工具

[返回分类目录](../README.md)

1. **carriage**，读音：/ˈkæ.rɪdʒ/，美式易读：KAR-ihj，读法理解：KAR：重读，a 像 cat 的 a，前接 k 的音、后接 r 的音；ihj：非重读，ih 像 sit 的 i，后接 j 的音，重音：主重音第1音节，中文：马车；客车；四轮马车；口语：① [I'm going to wash my carriage.](https://tatoeba.org/en/sentences/show/2358548) ② [How much do you reckon this carriage would cost?](https://tatoeba.org/en/sentences/show/6330512)

2. **chariot**，读音：/ˈtʃɛ.ri.ət/，美式易读：CHAIR-ee-uht，读法理解：CHAIR：重读，air 像 air 的读音，前接 ch 的音；ee：非重读，ee 像 see 的 ee；uht：轻读，uh 是 /ə/，嘴放松、短促轻读，后接 t 的音，重音：主重音第1音节，中文：战车；口语：① [In a swift chariot he crosses the ranks.](https://tatoeba.org/en/sentences/show/12360800) ② [A quadriga is a chariot drawn by four horses.](https://tatoeba.org/en/sentences/show/3115518)

3. **clarence**，读音：/ˈklɛ.rəns/，美式易读：KLAIR-uhns，读法理解：KLAIR：重读，air 像 air 的读音，前接 kl 的音；uhns：轻读，uh 是 /ə/，嘴放松、短促轻读，后接 ns 的音，重音：主重音第1音节，中文：克拉伦斯马车(一种四轮马车)；口语：① [Clarence Thomas and Samuel Alito are compromised and should be removed from office.](https://tatoeba.org/en/sentences/show/11865912) ② Can we talk about the clarence for a minute?

4. **donkey cart**，读音：/ˈdɑŋ.ki kɑrt/，美式易读：DAHNG-kee KART，读法理解：DAHNG：重读，ah 像 father 的 a，前接 d 的音、后接 ng 的音；kee：非重读，ee 像 see 的 ee，前接 k 的音；KART：单音节，ar 像 car 的 ar，前接 k 的音、后接 t 的音，重音：donkey：主重音第1音节；cart：单音节，中文：驴车；口语：① We passed a donkey cart on the road. ② That donkey cart is carrying a lot of vegetables.

5. **horse carriage**，读音：/hɔrs ˈkæ.rɪdʒ/，美式易读：HORS KAR-ihj，读法理解：HORS：单音节，or 像 more 的 ore，前接 h 的音、后接 s 的音；KAR：重读，a 像 cat 的 a，前接 k 的音、后接 r 的音；ihj：非重读，ih 像 sit 的 i，后接 j 的音，重音：horse：单音节；carriage：主重音第1音节，中文：马车；口语：① We took a ride in a horse carriage. ② Is that an old horse carriage in the museum?

6. **sedan chair**，读音：/sə.ˈdæn tʃɛr/，美式易读：suh-DAN CHAIR，读法理解：suh：轻读，uh 是 /ə/，嘴放松、短促轻读，前接 s 的音；DAN：重读，a 像 cat 的 a，前接 d 的音、后接 n 的音；CHAIR：单音节，air 像 air 的读音，前接 ch 的音，重音：sedan：主重音第2音节；chair：单音节，中文：轿子；口语：① Is that a sedan chair in the display? ② How many people carried a sedan chair like that?

7. **war chariot**，读音：/wɔr ˈtʃɛ.ri.ət/，美式易读：WOR CHAIR-ee-uht，读法理解：WOR：单音节，or 像 more 的 ore，前接 w 的音；CHAIR：重读，air 像 air 的读音，前接 ch 的音；ee：非重读，ee 像 see 的 ee；uht：轻读，uh 是 /ə/，嘴放松、短促轻读，后接 t 的音，重音：war：单音节；chariot：主重音第1音节，中文：战争马车；口语：① That museum has an old war chariot. ② How did people use a war chariot like this?
