# 日常动作 / 行为活动与安排

[返回分类目录](../README.md)

1. **ban**，读音：/bæn/，美式易读：BAN，读法理解：BAN：单音节，a 像 cat 的 a，前接 b 的音、后接 n 的音，重音：单音节，中文：禁令；口语：① [Let us not ban everything we disagree with.](https://tatoeba.org/en/sentences/show/5927291) ② [We must ban the Russian language on Tatoeba.](https://tatoeba.org/en/sentences/show/10688812)

2. **bans**，读音：/bænz/，美式易读：BANZ，读法理解：BANZ：单音节，a 像 cat 的 a，前接 b 的音、后接 nz 的音，重音：单音节，中文：结婚预告（等于banns）；口语：① [A society that bans religious headgear is not free.](https://tatoeba.org/en/sentences/show/11044190) ② [The treaty bans the use of chemical weapons.](https://tatoeba.org/en/sentences/show/268526)

3. **behavioral**，读音：/bɪ.ˈheɪv.jɚ.əl/，美式易读：bih-HAYV-yer-uhl，读法理解：bih：非重读，ih 像 sit 的 i，前接 b 的音；HAYV：重读，ay 像 day 的 ay，前接 h 的音、后接 v 的音；yer：轻读，er 像 teacher 的 er（轻读，带美式 r 音），前接 y 的音；uhl：轻读，uh 是 /ə/，嘴放松、短促轻读，后接 l 的音，重音：主重音第2音节，中文：行为的；口语：① [Have you tried cognitive behavioral therapy?](https://tatoeba.org/en/sentences/show/12154399) ② [Cognitive behavioral therapy doesn't work for everything or everyone.](https://tatoeba.org/en/sentences/show/11969319)

4. **behavioural**，读音：/biˈheivjәrәl/，美式易读：参考 bih-HAY-vyer-ruhl，读法理解：bih：非重读，ih 像 sit 的 i，前接 b 的音；HAY：重读，ay 像 day 的 ay，前接 h 的音；vyer：轻读，er 像 teacher 的 er（轻读，带美式 r 音），前接 vy 的音；ruhl：轻读，uh 是 /ə/，嘴放松、短促轻读，前接 r 的音、后接 l 的音，重音：主重音在ˈ之后的音节；ˌ为次重音，中文：行为的；口语：① The teacher mentioned some behavioural changes. ② Is that a behavioural issue or a learning difficulty?

5. **closeout**，读音：/ˈkləʊzaʊt/，美式易读：参考 KLOH-sowt，读法理解：KLOH：重读，oh 像 go 的 o，前接 kl 的音；sowt：非重读，ow 像 cow 的 ow，前接 s 的音、后接 t 的音，重音：主重音在ˈ之后的音节；ˌ为次重音，中文：出清存货；出清存货；口语：① Can we talk about the closeout for a minute? ② I still have a question about the closeout.

6. **closeouts**，读音：/ˈkləʊzˌaʊts/，美式易读：参考 KLOH-sowts，读法理解：KLOH：重读，oh 像 go 的 o，前接 kl 的音；sowts：非重读，ow 像 cow 的 ow，前接 s 的音、后接 ts 的音，重音：主重音在ˈ之后的音节；ˌ为次重音，中文：出清存货，出清存货( closeout的名词复数 )；口语：① Can we talk about the closeouts for a minute? ② I still have a question about the closeouts.

7. **fiat**，读音：/ˈfaɪ.æt/，美式易读：FEYE-at，读法理解：FEYE：重读，eye 像 eye 的读音，前接 f 的音；at：非重读，a 像 cat 的 a，后接 t 的音，重音：主重音第1音节，中文：命令；严命；口语：① [The current college works by presidential fiat.](https://tatoeba.org/en/sentences/show/1354417) ② [It's a fiat currency.](https://tatoeba.org/en/sentences/show/8636538)
