# 语言与表达 / 短语搭配与较少见表达 / 俚语口语与地区变体 / 地区用语与英语变体

1. **janis**，读音：/ˈdʒæ.nɪs/，美式易读：JAN-ihs，读法理解：JAN：重读，a 像 cat 的 a，前接 j 的音、后接 n 的音；ihs：非重读，ih 像 sit 的 i，后接 s 的音，重音：主重音第1音节，中文：口器颚颌；口语：① [Janis and Alma say that they had to speak Upper Sorbian.](https://tatoeba.org/en/sentences/show/8543744) ② Can we talk about the janis for a minute?

2. **kan**，读音：/kæn/，美式易读：KAN，读法理解：KAN：单音节，a 像 cat 的 a，前接 k 的音、后接 n 的音，重音：单音节，中文：赣江；口语：① Can we talk about the kan for a minute? ② I still have a question about the kan.

3. **och**，读音：/ɑk/，美式易读：AHK，读法理解：AHK：单音节，ah 像 father 的 a，后接 k 的音，重音：单音节，中文：阿；哦；口语：① Can we talk about the och for a minute? ② I still have a question about the och.

4. **southeastern**，读音：/ˌsaʊ.ˈθi.stɚn/，美式易读：sow-THEE-stern，读法理解：sow：次重读，ow 像 cow 的 ow，前接 s 的音；THEE：重读，ee 像 see 的 ee，前接 th 的音；stern：轻读，er 像 teacher 的 er（轻读，带美式 r 音），前接 st 的音、后接 n 的音，重音：主重音第2音节，中文：东南方的；口语：① [Croatia is in the southeastern part of Europe.](https://tatoeba.org/en/sentences/show/1396251) ② [Julia lives in a southeastern state of Brazil.](https://tatoeba.org/en/sentences/show/10265706)

5. **spelled**，读音：/spɛld/，美式易读：SPEHLD，读法理解：SPEHLD：单音节，eh 像 bed 的 e，前接 sp 的音、后接 ld 的音，重音：单音节，中文：spell的过去式和过去分词；口语：① [I don't remember how this word is spelled.](https://tatoeba.org/en/sentences/show/8207691) ② [Do you know how it's spelled?](https://tatoeba.org/en/sentences/show/10748505)
