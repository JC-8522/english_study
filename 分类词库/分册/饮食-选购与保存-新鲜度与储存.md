2. **cross-contamination**，读音：/krɔs kən.ˌtæ.mə.ˈneɪ.ʃən/，美式易读：KRAWS kuhn-ta-muh-NAY-shuhn，读法理解：KRAWS：单音节，aw 像 law 的 aw，前接 kr 的音、后接 s 的音；kuhn：轻读，uh 是 /ə/，嘴放松、短促轻读，前接 k 的音、后接 n 的音；ta：次重读，a 像 cat 的 a，前接 t 的音；muh：轻读，uh 是 /ə/，嘴放松、短促轻读，前接 m 的音；NAY：重读，ay 像 day 的 ay，前接 n 的音；shuhn：轻读，uh 是 /ə/，嘴放松、短促轻读，前接 sh 的音、后接 n 的音，重音：各词重音见美式易读的大写段；词组重读可随语境变化，中文：交叉污染；如生熟食品、过敏原等相互转移；口语：① Let's use a clean board to avoid cross-contamination. ② How can we prevent cross-contamination in this kitchen?

3. **freezer burn**，读音：/ˈfri.zɚ bɝn/，美式易读：FREE-zer BURN，读法理解：FREE：重读，ee 像 see 的 ee，前接 fr 的音；zer：轻读，er 像 teacher 的 er（轻读，带美式 r 音），前接 z 的音；BURN：单音节，ur 像 bird 的 ir（带美式 r 音），前接 b 的音、后接 n 的音，重音：各词重音见美式易读的大写段；词组重读可随语境变化，中文：冷冻灼伤；冷冻食品表面失水而出现的干斑等现象；口语：① This chicken has freezer burn. ② How do you keep freezer burn off your food?

6. **perishable**，读音：/ˈpɛ.rɪ.ʃə.bəl/，美式易读：PAIR-ih-shuh-buhl，读法理解：PAIR：重读，air 像 air 的读音，前接 p 的音；ih：非重读，ih 像 sit 的 i；shuh：轻读，uh 是 /ə/，嘴放松、短促轻读，前接 sh 的音；buhl：轻读，uh 是 /ə/，嘴放松、短促轻读，前接 b 的音、后接 l 的音，重音：主重音第1音节，中文：易腐坏的；需要相应储存条件的食品等；口语：① Let's put the perishable items away first. ② Which of these groceries are perishable?
