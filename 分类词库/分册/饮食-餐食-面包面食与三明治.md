# 饮食 / 餐食 / 面包面食与三明治

1. **bakery**，读音：/ˈbeɪ.kɚ.i/，美式易读：BAY-ker-ee，读法理解：BAY：重读，ay 像 day 的 ay，前接 b 的音；ker：轻读，er 像 teacher 的 er（轻读，带美式 r 音），前接 k 的音；ee：非重读，ee 像 see 的 ee，重音：主重音第1音节，中文：面包店；口语：① [You're still working part time at a bakery?](https://tatoeba.org/en/sentences/show/4098125) ② [We haven't heard of another bakery shop opening.](https://tatoeba.org/en/sentences/show/12879814)

2. **cereal**，读音：/ˈsɪ.ri.əl/，美式易读：SEER-ee-uhl，读法理解：SEER：重读，eer 像 near 的 ear，前接 s 的音；ee：非重读，ee 像 see 的 ee；uhl：轻读，uh 是 /ə/，嘴放松、短促轻读，后接 l 的音，重音：主重音第1音节，中文：谷类食品；谷类植物；口语：① [I can't eat bran cereal without fruit.](https://tatoeba.org/en/sentences/show/10227328) ② [I'll have some cereal and orange juice.](https://tatoeba.org/en/sentences/show/2192542)

3. **dough**，读音：/doʊ/，美式易读：DOH，读法理解：DOH：单音节，oh 像 go 的 o，前接 d 的音，重音：单音节，中文：生面团；口语：① [I put too much flour in the cookie dough.](https://tatoeba.org/en/sentences/show/9158885) ② [I rolled the dough to make some cookies.](https://tatoeba.org/en/sentences/show/681964)

4. **fried bologna sandwiches**，读音：/fraɪd bə.ˈloʊ.ni ˈsæn.dwɪ.tʃɪz/，美式易读：FREYED buh-LOH-nee SAN-dwih-chihz，读法理解：FREYED：单音节，eye 像 eye 的读音，前接 fr 的音、后接 d 的音；buh：轻读，uh 是 /ə/，嘴放松、短促轻读，前接 b 的音；LOH：重读，oh 像 go 的 o，前接 l 的音；nee：非重读，ee 像 see 的 ee，前接 n 的音；SAN：重读，a 像 cat 的 a，前接 s 的音、后接 n 的音；dwih：非重读，ih 像 sit 的 i，前接 dw 的音；chihz：非重读，ih 像 sit 的 i，前接 ch 的音、后接 z 的音，重音：fried：单音节；bologna：主重音第2音节；sandwiches：主重音第1音节，中文：煎博洛尼亚香肠三明治；口语：① My dad used to make fried bologna sandwiches. ② Have you ever tried fried bologna sandwiches?

5. **noodles**，读音：/ˈnu.dəlz/，美式易读：NOO-duhlz，读法理解：NOO：重读，oo 像 moon 的 oo，前接 n 的音；duhlz：轻读，uh 是 /ə/，嘴放松、短促轻读，前接 d 的音、后接 lz 的音，重音：主重音第1音节，中文：面条；挂面（noodle的复数形式）；口语：① [I'd like some noodles with scrambled eggs, please.](https://tatoeba.org/en/sentences/show/9795617) ② [I don't know how noodles are made.](https://tatoeba.org/en/sentences/show/6662901)
